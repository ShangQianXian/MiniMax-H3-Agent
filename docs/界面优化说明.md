# H3 工作区界面与交互优化

本次按提供的五张参考图调整现有 React 工作区，保留节点画布、共享 API 契约与本地代理架构。参考图用于配色、层级和排版；模型规格与费用仍取自项目的共享规则。

## 界面

- 将蓝黑色面板统一为中性深灰，降低边框和点阵的视觉强度，用少量淡紫色标识品牌、关联状态与焦点。
- 扩大侧栏导航的点击区域，统一线性图标；项目树保留在主层级，重复的项目管理内容改为折叠区。
- 画布使用圆角容器、曲线连线、右上角小地图和底部浮动工具栏；空白画布提供创作提示与模板入口。
- 创作台统一为素材区、提示词、字符计数和底部参数栏，支持扩展输入区、拖入素材、取消节点关联和打开创作指南。
- 费用使用人民币预估，不照搬参考图中平台积分。`× 1` 明确表示单次输出数量，不再随参考素材数变化。
- 节点设置与创作台设置共用 `GenerationControls`。按生成方式、比例、清晰度、时长和声音纵向分组；模型、水印和运行确认放入更多设置。
- 为桌面、较窄窗口和手机宽度设置断点；小屏隐藏次要文字和小地图，参数面板内部滚动。
- 图片节点完整显示图片比例，减少角色参考图被裁切的问题；视频播放控件不再触发参数弹窗。

## 已修复的问题

| 原问题 | 调整后的行为 |
| --- | --- |
| 没有目标节点时不能配置生成方式 | 草稿阶段即可完整设置参数 |
| 切换 H3 / H3-Max 遗留不支持的参数 | 自动修正分辨率、时长及参考模式，并展示模型支持的清晰度 |
| 默认只输入文字会留下 adaptive 比例 | 无参考素材时使用文生视频与具体比例，并在素材区显示说明 |
| 上传尚未结束仍能点击生成或用快捷键提交 | 上传期间统一禁用提交；同步锁拦截重复触发 |
| 不支持的文件先上传，批次失败丢失成功项 | 上传前检查类型与大小，逐项保留成功素材 |
| 超过 7000 字符仍可提交 | 明确标红并禁用按钮及快捷键 |
| 节点轮询覆盖正在编辑的草稿参数 | 仅在所选节点或参数内容改变时同步 |
| 绑定已有节点时费用仍按旧参数计算 | 使用草稿参数与已有上游、待添加素材共同估算 |
| 单张素材角色使用临时 ID，落地后失效 | 角色映射到实际节点 ID；参考视频不写入图片角色 |
| 切换工作流后草稿可能关联旧节点 | 清除跨工作流草稿与目标关联 |
| 参数弹窗偏移，多个输入端口重叠 | 将画布屏幕偏移计入定位，输入端口分别排列 |
| 生成节点被底部创作台遮住 | 新生成后聚焦相关节点，适应视图为创作台留出空间 |
| 新分支与现有节点重叠 | 新建分支放到现有图谱右侧；自动布局按节点实测高度留出间距 |
| 任务筛选读取旧状态，替换任务缓存后中断轮询 | 请求使用最新筛选值，筛选结果与全局任务缓存分开；过期响应不覆盖新结果 |
| 工具栏导入 JSON 失败后没有提示 | 显示可关闭的错误消息 |
| 取消生成后仍显示任务已完成 | 没有创建任务时提示内容已保留到画布 |
| 模拟模式确认文案声称必定产生费用 | 文案明确区分真实 API 与模拟模式 |

## 维护与构建

参数控件由一个组件维护，继续使用 `MODEL_CAPABILITIES`、`PRESETS`、`DURATIONS` 等共享定义。新增本地 SVG 图标组件，没有引入新的 UI 依赖。

生产构建拆分画布依赖、校验依赖与业务代码。单个业务入口由约 663 KB 降至约 377 KB，依赖可以独立缓存；这并不代表首次加载总下载量等比例减少。

正常使用仍可双击仓库根目录的 `启动.cmd`；无需 API 的体验使用 `启动-模拟模式.cmd`。

## 项目与工作流管理补充

项目树统一提供新建、重命名、删除入口。支持修改任意项目及当前项目内任意工作流的名称，重命名立即持久化且不改变画布。删除需明确确认，最后一个项目或工作流删除后展示新建入口。

同步修复新建项目残留旧工作流列表、删除非当前条目引起画布跳转、切换时遗漏防抖保存、删除后撤销恢复旧节点等问题。管理操作与画布保存分别串行执行；名称使用独立 PATCH 接口，避免自动保存覆盖新名称。前后端均校验名称并限制为 1–80 个字符。

新增 15 项回归测试，完整测试共 16 个文件、227 项通过，类型检查与生产构建通过。使用独立 `.vitest-data/project-management-preview` 数据目录验证桌面新建与重命名、刷新持久化、窄屏管理入口和删除确认取消流程，未修改正式项目数据。删除及异常处理由组件、状态和后端集成测试覆盖。
